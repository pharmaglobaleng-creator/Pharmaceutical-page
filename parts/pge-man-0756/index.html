Threaded-end versus unthreaded pin

The EXPRESS Product Control catalog lists a pin for the recirculating channel with a threaded end on page 86. Page 84 lists a pin with no threads. Both entries carry OEM cross-reference 48624, but their catalog replacement-part codes differ.

Choose by end form, not number alone

PGE-MAN-0756 identifies the threaded-end record. The separate PGE-MAN-0719 record identifies the pin with no threads. Do not treat the common reference as proof that either form can replace the other.

Confirming the installed pin

Send the existing pin or a drawing showing its end form with the EXPRESS machine identification. For the threaded version, include the thread specification and relevant dimensions if these are recorded in the machine documentation.

No thread diameter, pitch, handedness, engagement length or tightening torque is established by the catalog listing. Its description gives recirculating-channel context but does not document the pin’s complete mounting arrangement. Use the machine instructions for inspection or replacement; this identification record is not an installation procedure.
