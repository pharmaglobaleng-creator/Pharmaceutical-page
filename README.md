## Important
Placeholder pages use `noindex,follow` so incomplete content is not indexed. Remove `noindex` only after each page receives:
1. Final technical copy
2. Unique title and meta description
3. Canonical URL
4. Breadcrumbs
5. Internal links
6. Relevant schema
7. Reviewed images and alt text
8. Mobile and performance testing
