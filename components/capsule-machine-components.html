Capsule Machine Components: Identify the Assembly Before Ordering

Updated September 20, 2026

Capsule-filling components must be identified by their function, machine configuration and applicable format. A capsule size or machine brand alone is not a complete compatibility specification. Begin with the assembly in the machine manual and preserve the relationship between the component, its mating parts and its drawing reference.

Locate the component within the filling sequence

Capsule-filling equipment can include handling, separation, dosing, closing, ejection and cleaning functions. The parts involved depend on the machine design and installed options. Syntegon’s capsule-filling overview illustrates these stages for its GKF equipment; that example should not be treated as the layout of every capsule filler.

Describe the function at the affected station and identify the manual’s assembly name. A request for a “capsule segment” needs more context than a request tied to a particular upper or lower assembly and format. Dosing parts also need the installed dosing system identified. Do not assume two machines of the same broad family carry identical configurations.

Gather machine and format identity

Include manufacturer, model, serial information when available, capsule format and relevant modification history. Provide the component reference, assembly drawing and revision. Photograph markings separately so they can be read without losing the wider view of the part. State whether a number comes from the component, manual, packaging or an internal inventory label.

Keep reference types separate. A PharmaGlobalEng catalog identifier is not automatically an OEM number. If two references conflict, supply both and their sources. Compatibility must be resolved against the actual machine and assembly before a similar-looking item is selected.

Preserve the assembly relationship

Where permitted by site procedures, photograph the installed arrangement before removal and retain orientation information. Include mating features, spacers and adjacent components needed to understand the fit. A close-up of the broken area is useful for condition assessment but may omit the feature that determines compatibility.

When only a fragment is available, identify which dimensions and interfaces are missing. Do not reconstruct them from appearance and present them as measured facts. Ask whether an assembly drawing, intact counterpart or additional inspection is needed. Clearly labeled approximate information can assist an initial enquiry without becoming an unintended manufacturing specification.

Describe the problem separately from the part request

Record whether the concern is visible damage, assembly difficulty, capsule handling, dosing variation, closure or another observed symptom. Note whether it began after a changeover, cleaning, maintenance or a component change. These details can help identify the scope of review, but a process symptom does not prove that the component being ordered caused it.

Preserve relevant samples and records through the site’s procedures. Do not use this reference to adjust a dosing system, bypass an interlock or set installation clearances. Those decisions belong to the applicable machine instructions and approved site process.

Create an enquiry that can be quoted and checked

Send the machine and component identity, required quantity, drawings, photographs and a short statement of the observed condition. Say whether you need help identifying the part, confirmation of a listed item or review of a replacement specification. Include any documentation requirements before scope and price are agreed.

PharmaGlobalEng can receive the enquiry for scope and availability review; this page does not establish stock or compatibility for every machine. Confirm material, revision, interfaces and required documentation before purchase. Following receipt, use the site’s incoming and installation checks to verify the supplied item against the agreed order. Retain the approved cross-reference for the next enquiry rather than relying on visual memory.

Questions and answers

Does capsule size identify the complete format part?

No. Machine model, configuration, assembly and drawing details are also needed to establish compatibility.

Are dosing-disc and dosator parts interchangeable?

Do not assume so. Identify the installed dosing system and its specified component before requesting a replacement.

Can a broken fragment be used to order a part?

It may support identification, but missing dimensions and interfaces must be resolved using reliable reference information.

Should I include the machine serial number?

Include it when available, together with model and modification history, to help resolve configuration differences.

Does a catalog listing guarantee fit?

No. Match the listing to the actual machine and confirmed assembly requirements before purchase.

What if the required capsule component is not listed?

Send its reference, drawing or photographs with the machine details. Scope, compatibility and availability need confirmation.
